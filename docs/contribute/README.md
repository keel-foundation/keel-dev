# Contribution guides

Pick one path. You only need the repository for the change you are making.

| Guide | Use it when |
|---|---|
| [Get started](get-started.md) | You are new and want the general workflow. |
| [Repositories](repositories.md) | You need the public repository map. |
| [keel-core](keel-core.md) | You are changing the API, identity, channels, videos, or subscriptions. |
| [keel-pipeline](keel-pipeline.md) | You are changing ingest, transcode, packaging, or thumbnails. |
| [keel-moderation](keel-moderation.md) | You are changing signals, cases, appeals, review, or the ledger. |
| [Policy](policy.md) | You are changing policy, reason codes, review gates, or appeal windows. |
| [keel-spec](keel-spec.md) | You are changing schemas, OpenAPI, or RFCs. |
| [keel-web](keel-web.md) | You are changing the viewer, creator studio, or creator moderation record. |
| [keel-docs](keel-docs.md) | You are changing public creator or developer documentation. |
| [PR guidelines](pr-guidelines.md) | You are ready to open a pull request. |

The full local ecosystem is maintainer-only and lives in the private `keel-infra` repository. Public contributors run one module and use stage endpoints for the rest.
